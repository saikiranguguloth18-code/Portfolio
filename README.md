# Portfolio Website

A modern animated portfolio built with Next.js and Tailwind CSS. It includes a hero section, profile image, project showcase cards, skill badges, and a contact call-to-action.

## Getting started

```bash
npm install
npm run dev
```

Then open http://localhost:3000 in your browser.

## Scripts

- `npm run dev` — run the local development server
- `npm run build` — create a production build
- `npm run start` — run the production server
- `npm run lint` — check the code for lint issues
